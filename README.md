# BIMM143
The following are PDF files of my classwork from [BIMM 143](https://bioboot.github.io/bimm143_W26/) at UC San Diego WI26. BIMM 143 was a lecture/lab course offered to upper-division standing biology majors who were introduced to the principles of Bioinformatics in relation to R language, genes, and proteins. [Course completion certificates](DataCampCertifAquino.pdf) were received from DataCamp to gain additional basic knowledge in using R language. The course also briefly touched on terminal linux programming and the usage basic commands: "ls", "mv", "mkdir", and "cd." 

## [Final Project](Find_A_Gene_Project_Aquino.pdf)
The above is a Find-A-Gene project that acted as the final for the course based on a novel protein found using BLAST. Using methods learned throughout the course, multiple sequence alignments, a phylogenetic tree, a heatmap, and a 3D protein visual were created while also briefly discussing the druggability of the novel protein. 

## Index of Material 
**Class 01** [Introduction to Bioinformatics](BIMM143lab01_Aquino.pdf)

An introduction to BLAST, NCBI databases (GenBank, GENE, RefSeq, and OMIM), multiple sequence alignment, and 3D protein structure visualization. 

**Class 02** [Sequence Alignment Fundamentals, Algorithms, and Applications](BIMM143lab02_Aquino(1).pdf)

An introduction to plot parameters, pairwise sequence alignment, scoring matrix and a practice in using BLAST. 

**Class 03** [Advanced Sequence Alignment and Database Searching](BIMM143lab03_Aquino.pdf)

A deeper practice in using BLAST, position-specific scoring matrices, and multiple sequence alignments. 
  
**Class 04** [R Fundamentals](class04/class04.html)

An introduction to the RStudio console and Rmarkdown documents.

**Class 05** [Data Visualization with ggplot](class05/class05.html)

An introduction to ```ggplot()``` and data visualization practices in using simple graphics. 

**Class 06** [Writing Own R Functions](class06/class06.html)

A practice in writing R functions to ```generate_dna()``` and ```generate_protein()```.  

**Class 07** [Intro to Machine Learning](class07/class07.html)

An introduction to Kmeans Clustering, Hierarchical Clustering, Principal Component Analysis, Pair Plots, and Heatmaps.

**Class 08** [Cancer Cell Mini Project](class08/class08.html)

A practice in using previously introduced Machine Learning techniques and R language techniques to analyze breast cancer biopsy data.

**Class 09** [Candy Mini Project](class09/class09.html)

A practice in using previously learn analysis methods and an introduction to the following R language packages and functions to analyze a data set on candy:  ```dplyr```, ```skmir```, ```ggprel```, ```corrplot```, and ```prcomp()```.

**Class 10** [Structural Bioinformatics](class10/class10.html)

An introduction to the Protein Data Bank, Molestar, and the ```bio3d``` and ```bio3dview``` packages to visualize and analyze protein structure data. 

**Class 11** [AlphaFold](class11/class11.html)

An introduction to AlphaFold and "Cloud Computing".

**Class 12** [Genome Informatics](class12/class12.html)

A practice in using genome databased and genomic data sets to create plots and inferences. 

**Class 13** [Transcriptomics](class13/class13.html)

A introduction in RNASeq analysis using the ```DESeq2``` package and an introduction in pathway analysis using the ```gage``` and ```pathview``` packages. 

**Class 14** [RNA-Seq Mini-Project](class14/class14.html)

A practice in RNASeq analysis and pathway analysis on data on a HOX gene. 

**Class 17** [Analyzing Seq Data using AWS Cloud](class17/class17.html)

A practice in using AWS EC2 for sequence data analysis. 

**Class 18** [Pertussis Resurgence Mini-Project](class18/class18.html)

A practice in data visualization and analysis on a data set pertaining to Pertussis.
